Stationly pulls data directly from TfL Open Data, the same source used by official TfL apps and journey planners. Departure times are as accurate as TfL's own systems, and every board shows exactly when the data was last refreshed.

Departure times require a live connection. There is no way around that, since the data is real-time. If you go offline, the widget shows the last known times with a timestamp so you know how old the data is.
